# BlackStar Employee Management System

> A clean, secure and professional terminal-based Employee Data Management System with modern hacker aesthetic.

![Python](https://img.shields.io/badge/Python-3.8%2B-blue?style=flat-square&logo=python)
![License](https://img.shields.io/badge/License-MIT-green?style=flat-square)
![Platform](https://img.shields.io/badge/Platform-Windows%20%7C%20Linux%20%7C%20macOS-lightgrey?style=flat-square)

## ✨ Features

- ✅ Add New Employee
- ✅ Search Employee by ID
- ✅ View All Employees (Beautiful Table Format)
- ✅ Update Employee Details
- ✅ Delete Employee
- ✅ JSON-based Persistent Database
- ✅ Cross-Platform Support
- ✅ Colorful & Professional Terminal UI
- ✅ Input Validation & Error Handling
- ✅ Timestamp Tracking

## 🛠️ Tech Stack

- **Language**: Python 3.8+
- **Database**: JSON File
- **UI**: Colored Terminal Interface
